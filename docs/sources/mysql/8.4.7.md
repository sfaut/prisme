# MySQL 8.4.7 (2025-10-21)

Source: https://dev.mysql.com/doc/relnotes/mysql/8.4/en/news-8-4-7.html

## SQL Function and Operator Notes

- Fixed an issue related to executing certain UPDATE statements. (Bug #37590580) References: This issue is a regression of: Bug #31562881.

## Optimizer Notes

- Fixed an issue relating to SQL queries involving correlated scalar subqueries and JSON tables. (Bug #36684370)

## Bugs Fixed

- Logical clock handling for `CREATE ... SELECT` statements has been improved to ensure accurate logical clock values in the replica relay log. (Bug #38383106)
- The server sometimes processed table references incorrectly. (Bug #38001000)
- `PARTITION BY ... (DEFAULT (column`)) was not always handled correctly. (Bug #111234, Bug #35451459) References: This issue is a regression of: Bug #33142135.
