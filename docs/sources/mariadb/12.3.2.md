# MariaDB 12.3.2 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/12.3/12.3.2

MariaDB 12.3.2 is a Stable (GA) release of MariaDB Community Server 12.3, released on 2026-05-28

## New Features

### Compatibility Features

- Oracle [`TO_DATE()`](https://mariadb.com/docs/server/reference/sql-functions/date-time-functions/to_date.md) function ([MDEV-19683](https://jira.mariadb.com/browse/MDEV-19683))
- Support for [cursors](https://mariadb.com/docs/server/reference/sql-statements/programmatic-compound-statements/programmatic-compound-statements-cursors.md) on prepared statements ([MDEV-33830](https://jira.mariadb.com/browse/MDEV-33830))
- SQL Standard [`SET PATH`](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/set-commands/set-path.md) statement ([MDEV-34391](https://jira.mariadb.com/browse/MDEV-34391))
- SQL Standard [`IS JSON`](https://mariadb.com/docs/server/reference/sql-structure/operators/comparison-operators/is-json.md) predicate ([MDEV-37072](https://jira.mariadb.com/browse/MDEV-37072))
- Allow [`UPDATE`/`DELETE` to read from a CTE](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation/selecting-data/common-table-expressions.md) ([MDEV-37220](https://jira.mariadb.com/browse/MDEV-37220))
- Basic [XML data type](https://mariadb.com/docs/server/reference/data-types/string-data-types/xmltype.md) ([MDEV-37261](https://jira.mariadb.com/browse/MDEV-37261))

### Miscellaneous

- New hash algorithms for [`PARTITION BY KEY`](https://mariadb.com/docs/server/server-usage/partitioning-tables/partitioning-types/key-partitioning-type.md) ([MDEV-9826](https://jira.mariadb.com/browse/MDEV-9826))
- Optimize reorderable [LEFT JOINs](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation/selecting-data/joins/join-syntax.md) statements ([MDEV-36055](https://jira.mariadb.com/browse/MDEV-36055))
- Optimize ordered scans over [`PARTITION BY RANGE`](https://mariadb.com/docs/server/server-usage/partitioning-tables/partitioning-types/range-partitioning-type.md) ([MDEV-37330](https://jira.mariadb.com/browse/MDEV-37330))
