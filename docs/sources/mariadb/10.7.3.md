# MariaDB 10.7.3 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/10.7.3

## Notable Items

- This release fixes a blocking problem with the [MariaDB 10.7.2](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/10.7.2.md) release when manually running mariadb-upgrade. ([MDEV-27789](https://jira.mariadb.org/browse/MDEV-27789))
- See [MariaDB 10.7.2](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/10.7.2.md) for other changes since the previous release.
