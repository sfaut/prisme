# MariaDB: MDEV-33987

Source: https://jira.mariadb.org/browse/MDEV-33987

- Summary: Server crashes at `Item_func_as_wkt::val_str_ascii`.
- Affected versions: 11.3.2, 11.4.1.
- Fix versions: 10.5.28, 10.6.21, 10.11.11, 11.4.5, 11.6.2.
- Example of the ticket:

  ```sql
  SELECT ST_ASTEXT(BOUNDARY(INET6_ATON('255.255.255.255')));
  ```

Consulted for `BOUNDARY(0x41)` and `ST_BOUNDARY(0x41)`, bytes that are not a
geometry, which stop the server (signal 11; `probe calls`, then each call
alone with the exit status of the container, measured on each local image):
MariaDB 10.6.16, 10.6.17, 10.7.8 to 10.10.7, 10.11.2, 10.11.6, 10.11.7,
10.11.10, 11.0.2, 11.0.4, 11.0.5, 11.1.2 to 11.1.4, 11.1.6, 11.2.2, 11.2.3,
11.2.6, 11.3.2, 11.5.2 and 11.6.2; NULL in 10.5.29, 10.6.28, 10.11.14 to
10.11.19, 11.4.11 to 11.4.13, 11.7.2 and 11.8.7 to 11.8.9. The fix version
11.6.2 of the ticket does not match the measure: 11.6.2 still stops, 11.7.2
no longer does.
