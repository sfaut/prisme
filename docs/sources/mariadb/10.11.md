# MariaDB 10.11 Changes & Improvements

Source: https://mariadb.com/docs/release-notes/community-server/10.11/what-is-mariadb-1011

## New Features & Improvements

This list includes features from the short-term releases [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md), [MariaDB 10.8](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/what-is-mariadb-108.md), [MariaDB 10.9](https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/what-is-mariadb-109.md) and [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md).

### Optimizer

- Make [ANALYZE FORMAT=JSON](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/analyze-and-explain-statements/analyze-format-json.md) show time spent in the query optimizer ([MDEV-28926](https://jira.mariadb.org/browse/MDEV-28926))
- Improve optimization of joins with many tables, including eq\_ref tables ([MDEV-28852](https://jira.mariadb.org/browse/MDEV-28852), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))
- Table elimination does not work across derived tables ([MDEV-26278](https://jira.mariadb.org/browse/MDEV-26278), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))
- Histograms in the statistics tables are more precise and stored as JSON, not binary ([MDEV-21130](https://jira.mariadb.org/browse/MDEV-21130), [MDEV-26519](https://jira.mariadb.org/browse/MDEV-26519), [blog post](https://mariadb.org/10-7-preview-feature-json-histograms/), [MariaDB 10.8](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/what-is-mariadb-108.md)).
- Improve simple multibyte collation performance on the ASCII range ([MDEV-26572](https://jira.mariadb.org/browse/MDEV-26572), [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md)).

#### Descending Indexes

- Individual columns in the [index](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimization-and-indexes.md) can now be explicitly sorted in the ascending or descending order. This can be useful for optimizing certain [ORDER BY](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation/selecting-data/order-by.md) cases ([MDEV-13756](https://jira.mariadb.org/browse/MDEV-13756), [MDEV-26938](https://jira.mariadb.org/browse/MDEV-26938), [MDEV-26939](https://jira.mariadb.org/browse/MDEV-26939), [MDEV-26996](https://jira.mariadb.org/browse/MDEV-26996), [MariaDB 10.8](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/what-is-mariadb-108.md)).

### JSON

- [JSON\_OVERLAPS](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_overlaps.md) function ([MDEV-27677](https://jira.mariadb.org/browse/MDEV-27677), [MariaDB 10.9](https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/what-is-mariadb-109.md))
- Implement range notation for [JSONPath](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/jsonpath-expressions.md) ([MDEV-27911](https://jira.mariadb.org/browse/MDEV-27911), [MariaDB 10.9](https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/what-is-mariadb-109.md))
- Support [JSONPath](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/jsonpath-expressions.md) negative index ([MDEV-22224](https://jira.mariadb.org/browse/MDEV-22224), [MariaDB 10.9](https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/what-is-mariadb-109.md))
- [JSON\_EQUALS](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_equals.md) function to check for equality between JSON objects ([MDEV-23143](https://jira.mariadb.org/browse/MDEV-23143), [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md)).
- [JSON\_NORMALIZE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_normalize.md) function, which recursively sorts keys and removes spaces ([MDEV-16375](https://jira.mariadb.org/browse/MDEV-16375), [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md))

### UUID

- Add EXPLAIN FOR CONNECTION syntax support to [SHOW EXPLAIN](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-explain.md) ([MDEV-10000](https://jira.mariadb.org/browse/MDEV-10000), [MariaDB 10.9](https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/what-is-mariadb-109.md))

### UCA14 Collation

- Add UCA-14.0.0 [collations](https://mariadb.com/docs/server/reference/data-types/string-data-types/character-sets.md) ([MDEV-27009](https://jira.mariadb.org/browse/MDEV-27009), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))
- Improve contraction performance in UCA collations ([MDEV-27265](https://jira.mariadb.org/browse/MDEV-27265), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))
- Improve UCA collation performance for utf8mb3 and utf8mb4 ([MDEV-27266](https://jira.mariadb.org/browse/MDEV-27266), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))

### Convert Partitions

- ALTER TABLE ... CONVERT PARTITION .. TO TABLE ([MDEV-22166](https://jira.mariadb.org/browse/MDEV-22166), [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md)), and
- ALTER TABLE ... CONVERT TABLE ... TO PARTITION ... ([MDEV-22165](https://jira.mariadb.org/browse/MDEV-22165)) as an easy way to convert tables to partitions and back in one command, instead of a sequence of CREATE/EXCHANGE/DROP ([MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md))

### Miscellaneous

- Add [RANDOM\_BYTES](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/random_bytes.md) function ([MDEV-25704](https://jira.mariadb.org/browse/MDEV-25704), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))
- The [INET4](https://mariadb.com/docs/server/reference/data-types/string-data-types/inet4.md) data type ([MDEV-23287](https://jira.mariadb.org/browse/MDEV-23287), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))
- Re-design the upper level of handling UPDATE and DELETE statements ([MDEV-28883](https://jira.mariadb.org/browse/MDEV-28883), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))
- Deprecate the [DES\_ENCRYPT](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/des_encrypt.md)/[DECRYPT](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/des_decrypt.md) functions ([MDEV-27104](https://jira.mariadb.org/browse/MDEV-27104), [MariaDB 10.10](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/what-is-mariadb-1010.md))
- Stored procedures already have support for the [IN, OUT and INOUT](https://mariadb.com/docs/server/server-usage/stored-routines/stored-procedures/create-procedure.md#in-out-inout-in-out) parameter qualifiers. Added as well for [stored functions](https://mariadb.com/docs/server/reference/sql-statements/data-definition/create/create-function.md#in-or-out-or-inout-or-in-out) and (IN only) [cursors](https://mariadb.com/docs/server/reference/sql-statements/programmatic-compound-statements/programmatic-compound-statements-cursors/declare-cursor.md#in) ([MDEV-10654](https://jira.mariadb.org/browse/MDEV-10654)). This was a [contribution](https://github.com/MariaDB/server/pull/1931) by [ManoharKB](https://github.com/ManoharKB) ([MariaDB 10.8](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/what-is-mariadb-108.md)).
- Add an optional argument to the [CRC32()](https://mariadb.com/docs/server/reference/sql-functions/numeric-functions/crc32.md) function, as well as the [CRC32C()](https://mariadb.com/docs/server/reference/sql-functions/numeric-functions/crc32c.md) function, which uses the Castagnoli polynomial. ([MDEV-27208](https://jira.mariadb.org/browse/MDEV-27208)). Note: The order of the 2-ary arguments was swapped after the preview release: `crc32('MariaDB')=crc32(crc32('Maria'),'DB')` ([MariaDB 10.8](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/what-is-mariadb-108.md))
- [my\_print\_defaults](https://mariadb.com/docs/server/clients-and-utilities/administrative-tools/my_print_defaults.md) now handles `--default-*` options in exactly the same way as other MariaDB tools ([MDEV-26238](https://jira.mariadb.org/browse/MDEV-26238), [MariaDB 10.8](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/what-is-mariadb-108.md)).
- UCA [collations](https://mariadb.com/docs/server/reference/data-types/string-data-types/character-sets.md) are now notably faster ([MDEV-27266](https://jira.mariadb.org/browse/MDEV-27266), [MDEV-27265](https://jira.mariadb.org/browse/MDEV-27265), [MariaDB 10.8](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/what-is-mariadb-108.md)).
- [NATURAL\_SORT\_KEY](https://mariadb.com/docs/server/reference/sql-functions/string-functions/natural_sort_key.md) function ([MDEV-4742](https://jira.mariadb.org/browse/MDEV-4742), [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md)).
- Five provider plugins (bzip2, lzma, lz4, lzo, snappy) provide [compression capabilities](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimization-and-tuning-compression/compression-plugins.md) to the server and storage engines ([MDEV-12933](https://jira.mariadb.org/browse/MDEV-12933), [blog post](https://mariadb.org/10-7-preview-feature-provider-plugins), [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md)).
- [SFORMAT](https://mariadb.com/docs/server/reference/sql-functions/string-functions/sformat.md) function for arbitrary text formatting ([MDEV-25015](https://jira.mariadb.org/browse/MDEV-25015), [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md))
- [GET DIAGNOSTICS](https://mariadb.com/docs/server/reference/sql-statements/programmatic-compound-statements/programmatic-compound-statements-diagnostics/get-diagnostics.md) supports a new condition property name `ROW_NUMBER`. In multi-row inserts it allows one to retrieve a number of a row that has caused the error ([MDEV-10075](https://jira.mariadb.org/browse/MDEV-10075), [MDEV-26611](https://jira.mariadb.org/browse/MDEV-26611), [MariaDB 10.7](https://mariadb.com/docs/release-notes/community-server/old-releases/10.7/what-is-mariadb-107.md))
