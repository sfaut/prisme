# MariaDB 11.0 Changes & Improvements

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/11.0/what-is-mariadb-110

## New Features & Improvements

### Functions

- Given a time in picoseconds, the new function [FORMAT\_PICO\_TIME](https://mariadb.com/docs/server/reference/sql-functions/date-time-functions/format_pico_time.md) returns a human-readable time value and unit indicator ([MDEV-19629](https://jira.mariadb.org/browse/MDEV-19629))

### Optimizer

- Major improvements to the Optimizer. See [The Optimizer Cost Model from MariaDB 11.0](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizer/the-optimizer-cost-model-from-mariadb-11-0.md).

### Variables

- For a list of all new variables, see [System Variables Added in MariaDB 11.0](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/system-variables/system-and-status-variables-added-by-major-release/system-and-status-variables-added-by-major-unmaintained-release/system-variables-added-in-mariadb-11-0.md) and [Status Variables Added in MariaDB 11.0](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/system-variables/system-and-status-variables-added-by-major-release/system-and-status-variables-added-by-major-unmaintained-release/status-variables-added-in-mariadb-11-0.md).
