# MariaDB 12.1 Changes & Improvements

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/12.1/changes-and-improvements-in-mariadb-12.1

## New Features

### Performance improvements

- MDL scalability improvements ([MDEV-19749](https://jira.mariadb.org/browse/MDEV-19749))
- Faster [vector](https://mariadb.com/docs/server/reference/sql-structure/vectors.md) distance calculations via extrapolation ([MDEV-36205](https://jira.mariadb.org/browse/MDEV-36205))

### Compatibility features

- [( + ) for outer join syntax in Oracle mode](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation/selecting-data/joins/join-syntax.md#oracle-mode) ([MDEV-13817](https://jira.mariadb.org/browse/MDEV-13817))
- Associative arrays: DECLARE TYPE .. TABLE OF .. INDEX BY ([MDEV-34319](https://jira.mariadb.org/browse/MDEV-34319)) ([blog post](https://mariadb.org/bringing-oracles-associative-arrays-to-mariadb/))
- [DROP USER](https://mariadb.com/docs/server/reference/sql-statements/account-management-sql-statements/drop-user.md) will now by default issue a warning if the user has active sessions, or fail in [Oracle mode](https://mariadb.com/docs/release-notes/community-server/about/compatibility-and-differences/sql_modeoracle.md) ([MDEV-35617](https://jira.mariadb.org/browse/MDEV-35617))

### Optimizer

- Optimizations for GROUP/ORDER BY can make use of indexes on virtual columns ([MDEV-36132](https://jira.mariadb.org/browse/MDEV-36132))
- Include definitions of tables and views in the [optimizer trace](https://app.gitbook.com/s/WCInJQ9cmGjq1lsTG91E/development-articles/mariadb-internals/mariadb-internals-documentation-query-optimizer/mariadb-internals-documentation-optimizer-trace) ([MDEV-36483](https://jira.mariadb.org/browse/MDEV-36483))
  * [optimizer\_record\_context](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#optimizer_record_context) system variable.

#### Optimizer hints

- [Optimizer hints](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints.md): [\[NO\_\]JOIN\_INDEX](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints/index-level-hints.md#join_index-no_join_index), [\[NO\_\]GROUP\_INDEX](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints/index-level-hints.md#group_index-no_group_index), [\[NO\_\]ORDER\_INDEX](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints/index-level-hints.md#order_index-no_order_index), [\[NO\_\]INDEX](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints/index-level-hints.md#index-no_index) ([MDEV-35856](https://jira.mariadb.org/browse/MDEV-35856))
- [Optimizer hints](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints.md): [\[NO\_\]SPLIT\_MATERIALIZED](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints/table-level-hints.md#split_materialized-no_split_materialized) ([MDEV-36092](https://jira.mariadb.org/browse/MDEV-36092))
- [Optimizer hints](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints.md): [\[NO\_\]DERIVED\_CONDITION\_PUSHDOWN](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints/table-level-hints.md#derived_condition_pushdown-no_derived_condition_pushdown), [\[NO\_\]MERGE ](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimizer-hints/table-level-hints.md#merge-no_merge)([MDEV-36106](https://jira.mariadb.org/browse/MDEV-36106))

### Miscellaneous

- [Foreign key](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/optimization-and-indexes/foreign-keys.md) constraint names no longer need to be unique per database, only per table ([MDEV-28933](https://jira.mariadb.org/browse/MDEV-28933)) ([blog post](https://mariadb.org/per-table-unique-foreign-key-constraint-names-new-feature-in-mariadb-12-1/))

### Development Release Only

This feature was only available in the 12.1 development releases, and will be implemented in a later series.
