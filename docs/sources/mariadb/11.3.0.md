# MariaDB 11.3.0 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/11.3.0

Release date: 20 September 2023

## Connection Redirection

- Added a [redirect mechanism](https://mariadb.com/docs/server/ha-and-performance/connection-redirection-mechanism-in-the-mariadb-clientserver-protocol.md) using the [redirect\_url](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#redirect_url) system variable ([MDEV-15935](https://jira.mariadb.org/browse/MDEV-15935))
- At the moment client-side support is missing

## Data Types

- [INET4](https://mariadb.com/docs/server/reference/data-types/string-data-types/inet4.md) data types can now be cast into [INET6](https://mariadb.com/docs/server/reference/data-types/string-data-types/inet6.md) types ([MDEV-31626](https://jira.mariadb.org/browse/MDEV-31626))
- This means, INET4 values can be compared with INET6 values and can be inserted into INET6 columns, the server can automatically convert INET4 value into INET6 as needed.

## Functions

- Values generated by the Key Derivation Function [KDF](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/kdf.md) are resistant against password hashing generators, so are good for strongly hashed passwords ([MDEV-31474](https://jira.mariadb.org/browse/MDEV-31474)).

### Date and Time

- [DATE\_FORMAT](https://mariadb.com/docs/server/reference/sql-functions/date-time-functions/date_format.md) function can now print the current time zone abbreviation and current time zone offset from UTC with `%Z` and `%z` format specifiers. ([MDEV-31684](https://jira.mariadb.org/browse/MDEV-31684))

## Optimizer

- Queries like [UCASE(varchar\_col)=...](https://mariadb.com/docs/server/reference/sql-functions/string-functions/upper.md) can now use an index on `varchar_col` if its collation is case insensitive. An [optimizer\_switch](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/optimizer-switch.md) option, [sargable\_casefold=ON](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/sargable-upper.md), has been added to enable this optimization. ([MDEV-31496](https://jira.mariadb.org/browse/MDEV-31496))

## Processlist

- Added a `SENT_ROWS` column to the [Information Schema PROCESSLIST](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-processlist-table.md) table, as well as extended the display size for the columns in processlist to ensure that most results will fit in display ([MDEV-3953](https://jira.mariadb.org/browse/MDEV-3953))

## Application-Time Periods

- Note that this feature did not make it into [MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md), but is in [MariaDB 11.4](https://mariadb.com/docs/release-notes/community-server/11.4/what-is-mariadb-114.md).
- Add views for [periods](https://mariadb.com/docs/server/reference/sql-structure/temporal-tables/application-time-periods.md) in information\_schema ([MDEV-22597](https://jira.mariadb.org/browse/MDEV-22597)), in particular
- New view [INFORMATION\_SCHEMA.PERIODS](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-periods-table.md)
- New view [INFORMATION\_SCHEMA.KEY\_PERIOD\_USAGE](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-key_period_usage-table.md)
- New columns `IS_SYSTEM_TIME_PERIOD_START` and `IS_SYSTEM_TIME_PERIOD_END` in the [INFORMATION\_SCHEMA.COLUMNS](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-columns-table.md) view

## OLD\_MODE

- Setting a non-default [old\_mode](https://mariadb.com/docs/server/server-management/variables-and-modes/old_mode.md) value will now always issue a deprecation warning ([MDEV-31811](https://jira.mariadb.org/browse/MDEV-31811))

## Removed

The following deprecated features and system variables have been removed ([MDEV-32104](https://jira.mariadb.org/browse/MDEV-32104)):

- [debug](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#debug-debug_dbug) (deprecated since [MariaDB 5.5.37](https://mariadb.com/docs/release-notes/community-server/old-releases/5.5/5.5.37.md))
- sr\_YU [locale](https://mariadb.com/docs/server/reference/data-types/string-data-types/character-sets/internationalization-and-localization/server-locale.md) (deprecated since [MariaDB 10.0.11](https://mariadb.com/docs/release-notes/community-server/old-releases/10.0/10.0.11.md))
- "engine\_condition\_pushdown" in [optimizer\_switch](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/optimizer-switch.md) (deprecated since [MariaDB 10.1.1](https://mariadb.com/docs/release-notes/community-server/old-releases/10.1/10.1.1.md))
- [date\_format](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#date_format), [datetime\_format](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#datetime_format), [time\_format](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#time_format), [max\_tmp\_tables](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#max_tmp_tables) (deprecated since [MariaDB 10.1.2](https://mariadb.com/docs/release-notes/community-server/old-releases/10.1/10.1.2.md))
- "parser" in [mroonga](https://mariadb.com/docs/server/server-usage/storage-engines/mroonga.md) table comment (deprecated since [MariaDB 10.2.11](https://mariadb.com/docs/release-notes/community-server/old-releases/10.2/10.2.11.md))
