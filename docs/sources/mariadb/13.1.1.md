# MariaDB 13.1.1 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/13.1/13.1.1

MariaDB 13.1.1 is a Release Candidate (RC) release of MariaDB Community Server 13.1, released on 2026-09-15

## New Features

- Support for JSON operators [`column->path` and `column->>path`](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json-arrow-operators.md) ([MDEV-13594](https://jira.mariadb.org/browse/MDEV-13594))
- [DENY](https://mariadb.com/docs/server/reference/sql-statements/account-management-sql-statements/deny.md) clause for access control a.k.a. "negative grants" ([MDEV-14443](https://jira.mariadb.org/browse/MDEV-14443))
- [Auto-adding new partitions for `PARTITION BY RANGE`](https://mariadb.com/docs/server/server-usage/partitioning-tables/partitioning-types/range-columns-interval-partitioning.md) ([MDEV-15621](https://jira.mariadb.org/browse/MDEV-15621))
- Improve error reporting of [mysqlbinlog when used with `--flashback`](https://mariadb.com/docs/server/server-management/server-monitoring-logs/binary-log/flashback.md) ([MDEV-20749](https://jira.mariadb.org/browse/MDEV-20749))
- Locking full table scan fails to use table-level locking ([MDEV-24813](https://jira.mariadb.org/browse/MDEV-24813))
- Add [formatted column support to `JSON_TABLE`](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_table.md#format-json-columns) ([MDEV-25727](https://jira.mariadb.org/browse/MDEV-25727))
- [The default `utf8` character set is now `utf8mb4`](https://mariadb.com/docs/server/server-management/variables-and-modes/old_mode.md#utf8_is_utf8mb3) ([MDEV-30041](https://jira.mariadb.org/browse/MDEV-30041))
- New statement `CREATE TRIGGER FOR { STARTUP | SHUTDOWN }` ([MDEV-30645](https://jira.mariadb.org/browse/MDEV-30645))
- Optional lengths for string types: `VARCHAR[(N)]` ([MDEV-31414](https://jira.mariadb.org/browse/MDEV-31414))
- [`mariadbd --validate-config`](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#validate_config) to check the configuration for validity without starting the server ([MDEV-31527](https://jira.mariadb.org/browse/MDEV-31527))
- `NEW` and `OLD` in a trigger can be used as row variables ([MDEV-34723](https://jira.mariadb.org/browse/MDEV-34723))
- [`INFORMATION_SCHEMA.VECTOR_INDEXES`](https://mariadb.com/docs/server/reference/sql-structure/vectors/information-schema-vector_indexes-table.md) provides information about vector indexes ([MDEV-34805](https://jira.mariadb.org/browse/MDEV-34805))
- XMLISVALID() schema validation function ([MDEV-37262](https://jira.mariadb.org/browse/MDEV-37262))
- [`AND`/`OR` can now short-circuit](https://mariadb.com/docs/server/reference/sql-structure/operators/operator-precedence.md#short-circuit-evaluation) the execution for any argument not in a strictly left-to-right fashion ([MDEV-37713](https://jira.mariadb.org/browse/MDEV-37713), [MDEV-37714](https://jira.mariadb.org/browse/MDEV-37714))
- [`XXH3`](https://mariadb.com/docs/server/reference/sql-functions/numeric-functions/xxh3.md) and [`XXH32`](https://mariadb.com/docs/server/reference/sql-functions/numeric-functions/xxh32.md) hash functions ([MDEV-38180](https://jira.mariadb.org/browse/MDEV-38180))
- Adaptive hash index statistics is shown in ANALYZE FORMAT=JSON ([MDEV-38305](https://jira.mariadb.org/browse/MDEV-38305))
- Optimizer Context Recorder to record the optimizer data and then analyze query optimization on another server instance ([MDEV-38701](https://jira.mariadb.org/browse/MDEV-38701))
- MEMORY tables support variable-length data types, `VARCHAR` and `TEXT`/`BLOB` ([MDEV-38975](https://jira.mariadb.org/browse/MDEV-38975))
- Local routine variables usable in [`PREPARE`](https://mariadb.com/docs/server/reference/sql-statements/prepared-statements/prepare-statement.md#local-statement-names)/[`EXECUTE`](https://mariadb.com/docs/server/reference/sql-statements/prepared-statements/execute-statement.md)/[`DEALLOCATE`](https://mariadb.com/docs/server/reference/sql-statements/prepared-statements/deallocate-drop-prepare.md) and [`OPEN ... FOR`](https://mariadb.com/docs/server/reference/sql-statements/programmatic-compound-statements/programmatic-compound-statements-cursors/open.md) ([MDEV-39022](https://jira.mariadb.org/browse/MDEV-39022))
- [Package-wide TYPE declarations](https://mariadb.com/docs/server/reference/sql-statements/programmatic-compound-statements/declare-type.md#package-wide-types) ([MDEV-39587](https://jira.mariadb.org/browse/MDEV-39587))
- CHECK TABLE supports MEMORY tables ([MDEV-40030](https://jira.mariadb.org/browse/MDEV-40030))
- `slave_skip_errors` variable can be modified without server restart ([MDEV-7394](https://jira.mariadb.org/browse/MDEV-7394))
