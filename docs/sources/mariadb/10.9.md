# MariaDB 10.9 Changes & Improvements

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/what-is-mariadb-109

## New Features & Improvements

### JSON

- [JSON\_OVERLAPS](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_overlaps.md) function ([MDEV-27677](https://jira.mariadb.org/browse/MDEV-27677))
- Implement range notation for [JSONPath](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/jsonpath-expressions.md) ([MDEV-27911](https://jira.mariadb.org/browse/MDEV-27911))
- Support [JSONPath](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/jsonpath-expressions.md) negative index ([MDEV-22224](https://jira.mariadb.org/browse/MDEV-22224))

### SHOW ANALYZE FORMAT=JSON

- Extend [SHOW EXPLAIN](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-explain.md) to support SHOW ANALYZE \[FORMAT=JSON] ([MDEV-27021](https://jira.mariadb.org/browse/MDEV-27021))
- Add EXPLAIN FOR CONNECTION syntax support to [SHOW EXPLAIN](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-explain.md) ([MDEV-10000](https://jira.mariadb.org/browse/MDEV-10000))

### Variables

- For a list of all new variables, see [System Variables Added in MariaDB 10.9](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/system-variables/system-and-status-variables-added-by-major-release/system-and-status-variables-added-by-major-unmaintained-release/system-variables-added-in-mariadb-10-9.md).
- Merge [old](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#old) to [old\_mode](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#old_mode) sql variable ([MDEV-24920](https://jira.mariadb.org/browse/MDEV-24920))
The following variables have been deprecated:

- [old](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#old) (replaced by [old\_mode](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#old_mode))
and [Status Variables Added in MariaDB 10.9](https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/what-is-mariadb-109.md).
