# MariaDB 10.6.3 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/10.6/10.6.3

MariaDB 10.6.3 is a Stable (GA) release of MariaDB Community Server 10.6, released on 2021-07-06

## Notable Changes

### General

- The views [INFORMATION\_SCHEMA.KEYWORDS](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-keywords-table.md) and [INFORMATION\_SCHEMA.SQL\_FUNCTIONS](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-sql_functions-table.md) have been added to the information schema ([MDEV-25129](https://jira.mariadb.org/browse/MDEV-25129))
