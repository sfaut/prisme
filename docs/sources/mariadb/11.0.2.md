# MariaDB 11.0.2 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/11.0/11.0.2

Release date: 6 Jun 2023

## Notable Items

### Functions

- Given a time in picoseconds, the new function [FORMAT\_PICO\_TIME](https://mariadb.com/docs/server/reference/sql-functions/date-time-functions/format_pico_time.md) returns a human-readable time value and unit indicator ([MDEV-19629](https://jira.mariadb.org/browse/MDEV-19629))

### Optimizer

- [Split Materialized](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/optimizations-for-derived-tables/lateral-derived-optimization.md) optimization is improved to re-fill the materialized table only if necessary. The fewer number of table refills is taken into account when choosing query plan, too ([MDEV-26301](https://jira.mariadb.org/browse/MDEV-26301))
- New optimizer\_switch option, [hash\_join\_cardinality](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/hash_join_cardinality-optimizer_switch-flag.md), is added. It is ON by default. When set to ON, the optimizer will produce tighter bounds for hash join output cardinality. ([MDEV-30812](https://jira.mariadb.org/browse/MDEV-30812))
- [ANALYZE FORMAT=JSON](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/analyze-and-explain-statements/analyze-format-json.md) now prints more information about [Block Nested Loop joins](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizer/block-based-join-algorithms.md#block-nested-loop-join): `block-nl-join` element now has `r_loops`, `r_effective_rows` and `r_other_time_ms` fields ([MDEV-30806](https://jira.mariadb.org/browse/MDEV-30806), [MDEV-30830](https://jira.mariadb.org/browse/MDEV-30830), [MDEV-30972](https://jira.mariadb.org/browse/MDEV-30972)).

### Variables

- New status variable: [max\_used\_connections\_time](https://mariadb.com/docs/server/server-management/variables-and-modes/server-status-variables.md#max_used_connections_time) ([MDEV-30543](https://jira.mariadb.org/browse/MDEV-30543))
