# MariaDB 10.10.0 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/10.10.0

Release date: 23 Jun 2022

## Optimizer

- Improve optimization of joins with many tables, including eq\_ref tables ([MDEV-28852](https://jira.mariadb.org/browse/MDEV-28852))
- Table elimination does not work across derived tables ([MDEV-26278](https://jira.mariadb.org/browse/MDEV-26278))
Available as container: quay.io/mariadb-foundation/mariadb-devel:10.10-optimizer

## UCA14 Collation

- Add UCA-14.0.0 [collations](https://mariadb.com/docs/server/reference/data-types/string-data-types/character-sets.md) ([MDEV-27009](https://jira.mariadb.org/browse/MDEV-27009))
- Improve contraction performance in UCA collations ([MDEV-27265](https://jira.mariadb.org/browse/MDEV-27265))
- Improve UCA collation performance for utf8mb3 and utf8mb4 ([MDEV-27266](https://jira.mariadb.org/browse/MDEV-27266))
Available as container: quay.io/mariadb-foundation/mariadb-devel:10.10-uca14

## DDL

- [ALTER ONLINE TABLE](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table.md#alter-online-table) ([MDEV-16329](https://jira.mariadb.org/browse/MDEV-16329) not included in [MariaDB 10.10.1](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/10.10.1.md)
- Atomic CREATE OR REPLACE TABLE ([MDEV-25292](https://jira.mariadb.org/browse/MDEV-25292)) (not included in [MariaDB 10.10.1](https://mariadb.com/docs/release-notes/community-server/old-releases/10.10/10.10.1.md))
Available as container: quay.io/mariadb-foundation/mariadb-devel:10.10-ddl

## Miscellaneous

- Change default of [explicit\_defaults\_for\_timestamp](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#explicit_defaults_for_timestamp) to ON ([MDEV-28632](https://jira.mariadb.org/browse/MDEV-28632))
- \--ssl option set as default for mariadb CLI ([MDEV-27105](https://jira.mariadb.org/browse/MDEV-27105))
- Add [RANDOM\_BYTES](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/random_bytes.md) function ([MDEV-25704](https://jira.mariadb.org/browse/MDEV-25704))
- The [INET4](https://mariadb.com/docs/server/reference/data-types/string-data-types/inet4.md) data type ([MDEV-23287](https://jira.mariadb.org/browse/MDEV-23287))
- Re-design the upper level of handling UPDATE and DELETE statements ([MDEV-28883](https://jira.mariadb.org/browse/MDEV-28883))
- Deprecate the [DES\_ENCRYPT](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/des_encrypt.md)/[DECRYPT](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/des_decrypt.md) functions ([MDEV-27104](https://jira.mariadb.org/browse/MDEV-27104))
Available as container: quay.io/mariadb-foundation/mariadb-devel:10.10-misc
