# MariaDB 10.9.3 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/10.9.3

Release date: 19 Sep 2022

## Notable Items

### Issues Fixed

- Recovery or backup of instant ALTER TABLE is incorrect ([MDEV-29438](https://jira.mariadb.org/browse/MDEV-29438))
- Full text index corruption if shutdown before changes are fully flushed ([MDEV-29342](https://jira.mariadb.org/browse/MDEV-29342))
- [JSON\_VALUE()](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_value.md) does not parse NULL properties properly ([MDEV-27151](https://jira.mariadb.org/browse/MDEV-27151))
