# MariaDB 10.6.20 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/10.6/10.6.20

MariaDB 10.6.20 is a Stable (GA) release of MariaDB Community Server 10.6, released on 2024-11-01

## Notable Items

### Data Definition - Alter Table

- Modification of the column now correctly checks foreign key constraint ([MDEV-34392](https://jira.mariadb.org/browse/MDEV-34392))
- Fix incorrect NULL value handling for instantly dropped BLOB columns ([MDEV-35122](https://jira.mariadb.org/browse/MDEV-35122))

### JSON

- [JSON\_TABLE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_table.md) now properly unquotes strings ([MDEV-27412](https://jira.mariadb.org/browse/MDEV-27412))
- [JSON\_TABLE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_table.md) default values now allows non-string literals ([MDEV-25822](https://jira.mariadb.org/browse/MDEV-25822))

### General

- LOAD DATA INFILE with geometry data no longer fails ([MDEV-34883](https://jira.mariadb.org/browse/MDEV-34883))
- Trigger now works correctly with bulk update ([MDEV-34718](https://jira.mariadb.org/browse/MDEV-34718))
- Add new setting, [--quick-max-column-width](https://mariadb.com/docs/server/clients-and-utilities/mariadb-client/mariadb-command-line-client.md#quick-max-column-width-n) to the mariadb client for use in --quick mode ([MDEV-34704](https://jira.mariadb.org/browse/MDEV-34704))
