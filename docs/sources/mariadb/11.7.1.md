# MariaDB 11.7.1 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/11.7/11.7.1

Release date: 21 Nov 2024

## Notable Items

### Vectors

- [Vectors](https://mariadb.com/docs/server/reference/sql-structure/vectors.md) are a feature that allow MariaDB Server to perform as a relational vector database. Previously available in the special [Vector preview release](https://mariadb.com/docs/release-notes/community-server/old-releases/11.6/11.6.0-vector.md), it has now been added to MariaDB Community Server 11.7.1 with various enhancements ([MDEV-34939](https://jira.mariadb.org/browse/MDEV-34939))
  * Data type VECTOR ([MDEV-33410](https://jira.mariadb.org/browse/MDEV-33410))
  * Conversion functions VEC\_FromText and VEC\_ToText ([MDEV-32886](https://jira.mariadb.org/browse/MDEV-32886))
  * Configuration options ([MDEV-35244](https://jira.mariadb.org/browse/MDEV-35244))
    * [mhnsw\_max\_cache\_size](https://mariadb.com/docs/server/reference/sql-structure/vectors/vector-system-variables.md#mhnsw_max_cache_size) Upper limit for one MHNSW vector index cache
    * [mhnsw\_default\_distance](https://mariadb.com/docs/server/reference/sql-structure/vectors/vector-system-variables.md#mhnsw_default_distance) Default value for the DISTANCE vector index option
    * [mhnsw\_default\_m](https://mariadb.com/docs/server/reference/sql-structure/vectors/vector-system-variables.md#mhnsw_default_m) Default value for the M vector index option
    * [mhnsw\_ef\_search](https://mariadb.com/docs/server/reference/sql-structure/vectors/vector-system-variables.md#mhnsw_ef_search) Defines the minimal number of result candidates to look for in the vector index for ORDER BY … LIMIT N queries.

### Data Definition - Alter Table

- Fix case where modification of the column incorrectly checked foreign key constraint ([MDEV-34392](https://jira.mariadb.org/browse/MDEV-34392))
- Fix incorrect NULL value handling for instantly dropped BLOB columns ([MDEV-35122](https://jira.mariadb.org/browse/MDEV-35122))

### JSON

- [JSON\_TABLE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_table.md) now properly unquotes strings ([MDEV-27412](https://jira.mariadb.org/browse/MDEV-27412))
- [JSON\_TABLE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_table.md) default values now allows non-string literals ([MDEV-25822](https://jira.mariadb.org/browse/MDEV-25822))

### UUID

- New function for generating version 4 UUIDs [UUIDv4](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/miscellaneous-functions/uuid_v4.md) ([MDEV-11339](https://jira.mariadb.org/browse/MDEV-11339))
- New function for generating version 7 UUIDs [UUIDv7](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/miscellaneous-functions/uuid_v7.md) ([MDEV-32637](https://jira.mariadb.org/browse/MDEV-32637))

### General

- LOAD DATA INFILE with geometry data no longer fails ([MDEV-34883](https://jira.mariadb.org/browse/MDEV-34883))
- Trigger now works correctly with bulk update ([MDEV-34718](https://jira.mariadb.org/browse/MDEV-34718))
- Add new setting, [--quick-max-column-width](https://mariadb.com/docs/server/clients-and-utilities/mariadb-client/mariadb-command-line-client.md#quick-max-column-width-n) to the mariadb client for use in --quick mode ([MDEV-34704](https://jira.mariadb.org/browse/MDEV-34704))
