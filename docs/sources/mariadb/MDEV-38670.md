# MariaDB: MDEV-38670

Source: https://jira.mariadb.org/browse/MDEV-38670

- Summary: Minus string is converted to -0.
- Affected versions: 10.11, 11.4, 11.8.
- Fix versions: 10.6.26, 10.11.17, 11.4.11, 11.8.7, 12.3.2.
- Example of the ticket: `SELECT @x := -''` gives `-0`, `SELECT @y := 0 - ''`
  gives `0`, both with the warning "Truncated incorrect DOUBLE value";
  `-@x` gives `0`, `--@x` gives `-0`.

The release notes of the fix versions describe it as: Change the "-0"
results in many SELECT scenarios to just return "0". From these versions,
MariaDB writes `0` for every negative zero of a float measured: the literal
`-0e0`, `-(f - f)`, `CONCAT`, `CAST` to `DOUBLE` or `CHAR`, `GREATEST`,
`ROUND`, `CEILING` (`crates/probe/cases/negative-zero.txt`, measured on each
local image); before, `-0`, as MySQL writes it.
