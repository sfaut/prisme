# MariaDB: MDEV-33659

Source: https://jira.mariadb.org/browse/MDEV-33659

- Summary: Server crashed at `Create_func_aes_decrypt::create_native`.
- Affected versions: 11.3.2, 11.4.1.
- Fix versions: 11.2.4, 11.4.2.
- Example of the ticket:

  ```sql
  SELECT AES_DECRYPT ( );
  ```

Consulted for `AES_DECRYPT()`, `AES_ENCRYPT()` and `KDF()` without
arguments, which stop the server (signal 11; `probe calls`, then each call
alone with the exit status of the container, measured on each local image):
`AES_DECRYPT()` and `AES_ENCRYPT()` on MariaDB 11.2.2, 11.2.3 and 11.3.2,
`KDF()` on 11.3.2, its first version measured (error 1305 before 11.3);
error 1582 (incorrect parameter count) on the other images, 11.2.6 among
them, as the fix version 11.2.4 of the ticket says. The ticket names only
`AES_DECRYPT`; the functions of variable arity that 11.2.0 and 11.3.0 added
(MDEV-9069, MDEV-31474) share the defect.
