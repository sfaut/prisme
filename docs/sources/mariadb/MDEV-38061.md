# MariaDB: MDEV-38061

Source: https://jira.mariadb.org/browse/MDEV-38061

- Summary: Assertion `args[0]->decimal_precision() < 22` failed in
  `Item_func_round::fix_arg_hex_hybrid`.
- Fix versions: 10.11.19, 11.4.13, 11.8.9, 12.3.3.
- Example of the ticket:

  ```sql
  SELECT ROUND(NAME_CONST('x', 0x0123456789ABCDEF0123456789ABCDEF0123456789AB));
  ```

The ticket fixes the type of a hexadecimal literal in `ROUND`. The same
versions read a hexadecimal literal as a number when all the results of
`CASE`, `IF`, `IFNULL`, `COALESCE` or `NULLIF` are such literals
(`IF(1, 0x41, 0x42) + 0` gives 65 from 10.11.19, 11.4.13 and 11.8.9, 0
before; `crates/probe/cases/literals-hex-results.txt`), which the ticket does
not describe: construct `hybrid_result_number` of
`crates/dialects/reference/mariadb.yaml`.

Found by the API of the Jira, among the tickets of 11.8.9:

```
GET https://jira.mariadb.org/rest/api/2/search
  ?jql=fixVersion = "11.8.9" AND (text ~ "hex" OR text ~ "hybrid" OR text ~ "COALESCE" OR text ~ "CASE")
  &fields=summary,fixVersions
```

Of the 112 tickets found, the others concern crashes, storage engines,
replication and Galera; MDEV-37865 ("IF() function is returning incorrect
error", 10.6.28 and later) concerns the errors of `IF`.
