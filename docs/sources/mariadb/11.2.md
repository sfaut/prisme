# MariaDB 11.2 Changes & Improvements

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112

## New Features & Improvements

### Online Schema Change

- [ALTER TABLE](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table.md) can now do most operations with `ALGORITHM=COPY, LOCK=NONE`, that is, in most cases, unless the algorithm and lock level are explicitly specified, `ALTER TABLE` will be performed using the [COPY](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table.md#algorithm-copy) algorithm while simultaneously allowing concurrent [DML statements](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation.md) on the altered table.
For more information, refer to, [Online Schema Change](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table/online-schema-change.md).

### JSON

- [JSON\_TABLE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_table.md) now allows retrieval of the key when iterating on JSON objects ([MDEV-30145](https://jira.mariadb.org/browse/MDEV-30145))
- New functions [JSON\_OBJECT\_FILTER\_KEYS](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_object_filter_keys.md), [JSON\_OBJECT\_TO\_ARRAY](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_object_to_array.md) and [JSON\_ARRAY\_INTERSECT](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_array_intersect.md) to check for JSON intersection ([MDEV-26182](https://jira.mariadb.org/browse/MDEV-26182))
- [JSON\_KEY\_VALUE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_key_value.md) extracts key/value pairs from a JSON object ([MDEV-30145](https://jira.mariadb.org/browse/MDEV-30145))

### Miscellaneous

- [ALTER TABLE IMPORT](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table.md) enhancement ([MDEV-26137](https://jira.mariadb.org/browse/MDEV-26137))
- Temporary tables are now displayed in the [Information Schema TABLES Table](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-tables-table.md), [SHOW TABLES](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-tables.md) and [SHOW TABLE STATUS](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-table-status.md) ([MDEV-12459](https://jira.mariadb.org/browse/MDEV-12459))
- [Stored programs](https://mariadb.com/docs/server/server-usage/stored-routines.md): validation of stored program statements ([MDEV-5816](https://jira.mariadb.org/browse/MDEV-5816))
- Remove the deprecated [old\_alter\_table](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#old_alter_table) variable ([MDEV-30905](https://jira.mariadb.org/browse/MDEV-30905))
- Extend [AES\_ENCRYPT()](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/aes_encrypt.md) and [AES\_DECRYPT()](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/aes_decrypt.md) to support an initialization vector and algorithm ([MDEV-9069](https://jira.mariadb.org/browse/MDEV-9069))
