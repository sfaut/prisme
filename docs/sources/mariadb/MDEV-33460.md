# MariaDB: MDEV-33460

Source: https://jira.mariadb.org/browse/MDEV-33460

- Summary: select '123' 'x'; unexpected result.
- Affected versions: 10.6.15, 11.4.
- Fix versions: 10.5.25, 10.6.18, 10.11.8, 11.0.6, 11.1.5, 11.2.4, released
  on 2024-05-16; none for 11.3, whose last version, 11.3.2, came out before.
- Example of the ticket: `SELECT '123' 'x'` gives the value `123x` in a
  column named `123` before the fix, `123x` after.
- Changelog note of the ticket: adjacent string literals are concatenated;
  when a string literal is alone as an item of the select list, its value
  names the column; before the fix, only the first literal named it.
