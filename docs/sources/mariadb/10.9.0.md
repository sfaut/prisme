# MariaDB 10.9.0 Release Notes

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/10.9.0

Release date: 23 March 2022

## JSON

- [JSON\_OVERLAPS](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_overlaps.md) function ([MDEV-27677](https://jira.mariadb.org/browse/MDEV-27677))
- Implement range notation for [JSONPath](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/jsonpath-expressions.md) ([MDEV-27911](https://jira.mariadb.org/browse/MDEV-27911))
- Support [JSONPath](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/jsonpath-expressions.md) negative index ([MDEV-22224](https://jira.mariadb.org/browse/MDEV-22224))

## SHOW ANALYZE FORMAT=JSON

- Extend [SHOW EXPLAIN](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-explain.md) to support \[SHOW ANALYZE [FORMAT=JSON](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-analyze.md)] ([MDEV-27021](https://jira.mariadb.org/browse/MDEV-27021))
- Add EXPLAIN FOR CONNECTION syntax support to [SHOW EXPLAIN](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-explain.md) ([MDEV-10000](https://jira.mariadb.org/browse/MDEV-10000))

## Miscellaneous

- [information\_schema.tables.table\_type](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-tables-table.md) now shows TEMPORARY for local temporary tables ([MDEV-12459](https://jira.mariadb.org/browse/MDEV-12459)) (not included in [MariaDB 10.9.1](https://mariadb.com/docs/release-notes/community-server/old-releases/10.9/10.9.1.md))
- Merge [old](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#old) to [old\_mode](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#old_mode) sql variable ([MDEV-24920](https://jira.mariadb.org/browse/MDEV-24920))
