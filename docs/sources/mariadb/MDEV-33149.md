# MariaDB: MDEV-33149

Source: https://jira.mariadb.org/browse/MDEV-33149

- Summary: `JSON_ARRAY_INTERSECT` function crashes the server when called
  with empty JSON arrays.
- Affected versions: 11.2.3, 11.3.2, 11.4.0, 11.5.0; absent from 10.4.33 to
  11.1.4, before the function (MDEV-26182, 11.2.0).
- Fix versions: 11.4.9, 11.8.4, 12.1.2, 12.2.1.
- Example of the ticket: `SELECT json_array_intersect(@a,@b);`, two user
  variables that are not set, so NULL. The crash is a SIGSEGV in
  `Item_func_json_array_intersect::prepare_json_and_create_hash`.

Consulted for `JSON_ARRAY_INTERSECT(NULL, 1)`, which stops the server
(signal 11; `probe calls`, then the call alone with the exit status of the
container, measured on each local image): MariaDB 11.2.2, 11.2.3, 11.2.6,
11.3.2, 11.5.2, 11.6.2 and 11.7.2; NULL in 11.4.11 to 11.4.13 and 11.8.7 to
11.8.9; error 1305 before 11.2.
