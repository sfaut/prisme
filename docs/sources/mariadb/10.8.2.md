# MariaDB 10.8.2 Release notes

Source: https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/10.8.2

## Notable Items

- This release fixes a blocking problem with the [MariaDB 10.8.1](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/10.8.1.md) release when manually running mariadb-upgrade. ([MDEV-27789](https://jira.mariadb.org/browse/MDEV-27789))
- See [MariaDB 10.8.1](https://mariadb.com/docs/release-notes/community-server/old-releases/10.8/10.8.1.md) for other changes since the previous release.

### General

- Fix mismatched braces for non-Linux targets (fails to build) ([MDEV-27790](https://jira.mariadb.org/browse/MDEV-27790))
