# MariaDB 11.4 Changes & Improvements

Source: https://mariadb.com/docs/release-notes/community-server/11.4/what-is-mariadb-114

## New Features

This list includes all features since the previous long-term release, [MariaDB 10.11](https://mariadb.com/docs/release-notes/community-server/10.11/what-is-mariadb-1011.md) (those introduced in the [MariaDB 11.0](https://mariadb.com/docs/release-notes/community-server/old-releases/11.0/what-is-mariadb-110.md), [MariaDB 11.1](https://mariadb.com/docs/release-notes/community-server/old-releases/11.1/what-is-mariadb-111.md) and [MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md) short-term releases, and the [MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md) rolling release).

### Optimizer

- Major improvements to the Optimizer. See [The Optimizer Cost Model from MariaDB 11.0](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizer/the-optimizer-cost-model-from-mariadb-11-0.md).
- [Semi-join optimization](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/subquery-optimizations/semi-join-subquery-optimizations.md) for single-table [UPDATE](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation/changing-deleting-data/update.md)/[DELETE](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation/changing-deleting-data/delete.md) statements. Update and delete statements that use subqueries can now use all subquery optimization strategies that MariaDB offers, so now if you use subqueries in UPDATE or DELETE, these statements will likely be much faster ([MDEV-7487](https://jira.mariadb.org/browse/MDEV-7487), [MariaDB 11.1](https://mariadb.com/docs/release-notes/community-server/old-releases/11.1/what-is-mariadb-111.md))
- Queries with the [DATE](https://mariadb.com/docs/server/reference/sql-functions/date-time-functions/date-function.md) or [YEAR](https://mariadb.com/docs/server/reference/sql-functions/date-time-functions/year.md) functions comparing against a constant can now make use of indexes, so these will be noticeably quicker in certain instances. For example `SELECT * FROM t2 WHERE YEAR(a) = 2019` or `SELECT * FROM t2 WHERE DATE(a) <= '2017-01-01'`. See [Sargable DATE and YEAR](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/sargable-date-and-year.md) ([MDEV-8320](https://jira.mariadb.org/browse/MDEV-8320), [MariaDB 11.1](https://mariadb.com/docs/release-notes/community-server/old-releases/11.1/what-is-mariadb-111.md))
- Queries like [UCASE(varchar\_col)=...](https://mariadb.com/docs/server/reference/sql-functions/string-functions/upper.md) can now use an index on `varchar_col` if its collation is case insensitive. An [optimizer\_switch](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/optimizer-switch.md) option, [sargable\_casefold=ON](https://mariadb.com/docs/server/ha-and-performance/optimization-and-tuning/query-optimizations/sargable-upper.md), has been added to enable this optimization. ([MDEV-31496](https://jira.mariadb.org/browse/MDEV-31496), [MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md))
- Not only ascending, but also [descending indexes](https://mariadb.com/docs/server/server-usage/tables/create-table.md#index-types) can now be used to optimize [MIN()](https://mariadb.com/docs/server/reference/sql-functions/aggregate-functions/min.md) and [MAX()](https://mariadb.com/docs/server/reference/sql-functions/aggregate-functions/max.md) ([MDEV-27576](https://jira.mariadb.org/browse/MDEV-27576))

### Online Schema Change

- [ALTER TABLE](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table.md) can now do most operations with `ALGORITHM=COPY, LOCK=NONE`, that is, in most cases, unless the algorithm and lock level are explicitly specified, `ALTER TABLE` will be performed using the [COPY](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table.md#algorithm-copy) algorithm while simultaneously allowing concurrent [DML statements](https://mariadb.com/docs/server/reference/sql-statements/data-manipulation.md) on the altered table. ([MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md))
For more information, refer to, [Online Schema Change](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table/online-schema-change.md).

### JSON

- [JSON\_TABLE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_table.md) now allows retrieval of the key when iterating on JSON objects ([MDEV-30145](https://jira.mariadb.org/browse/MDEV-30145), [MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md))
- New functions [JSON\_OBJECT\_FILTER\_KEYS](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_object_filter_keys.md), [JSON\_OBJECT\_TO\_ARRAY](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_object_to_array.md) and [JSON\_ARRAY\_INTERSECT](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_array_intersect.md) to check for JSON intersection ([MDEV-26182](https://jira.mariadb.org/browse/MDEV-26182), [MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md))
- [JSON\_KEY\_VALUE](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_key_value.md) extracts key/value pairs from a JSON object ([MDEV-30145](https://jira.mariadb.org/browse/MDEV-30145), [MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md))
- [JSON\_SCHEMA\_VALID](https://mariadb.com/docs/server/reference/sql-functions/special-functions/json-functions/json_schema_valid.md) function for validating a JSON schema ([MDEV-27128](https://jira.mariadb.org/browse/MDEV-27128), [MariaDB 11.1](https://mariadb.com/docs/release-notes/community-server/old-releases/11.1/what-is-mariadb-111.md))

### Data Types

- It is now possible to create [partitions](https://mariadb.com/docs/server/server-usage/partitioning-tables.md) on tables that contain [GEOMETRY types](https://mariadb.com/docs/server/reference/sql-structure/geometry/geometry-types.md) ([MDEV-19177](https://jira.mariadb.org/browse/MDEV-19177), [MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md))
- [INET4](https://mariadb.com/docs/server/reference/data-types/string-data-types/inet4.md) data types can now be cast into [INET6](https://mariadb.com/docs/server/reference/data-types/string-data-types/inet6.md) types ([MDEV-31626](https://jira.mariadb.org/browse/MDEV-31626), [MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md))
- This means INET4 values can be compared with INET6 values and can be inserted into INET6 columns;\
  the server can automatically convert INET4 value into INET6 as needed ([MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md))

### Application-Time Periods

- Add views for [periods](https://mariadb.com/docs/server/reference/sql-structure/temporal-tables/application-time-periods.md) in information\_schema ([MDEV-22597](https://jira.mariadb.org/browse/MDEV-22597)), in particular
- New view [INFORMATION\_SCHEMA.PERIODS](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-periods-table.md)
- New view [INFORMATION\_SCHEMA.KEY\_PERIOD\_USAGE](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-key_period_usage-table.md)
- New columns `IS_SYSTEM_TIME_PERIOD_START` and `IS_SYSTEM_TIME_PERIOD_END` in the [INFORMATION\_SCHEMA.COLUMNS](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-columns-table.md) view

### Sys Schema

- New view [sys.privileges\_by\_table\_by\_level](https://mariadb.com/docs/server/reference/system-tables/sys-schema/sys-schema-views/privileges_by_table_by_level-sys-schema-view.md) shows granted privileges broken down by table on which they allow access and level on which they were granted. For example, if a user `x` has `SELECT` privilege granted `ON db.*`, this view will list all tables in the `db` schema with the user `x` having `SELECT` privilege on them. This is different from [INFORMATION\_SCHEMA.TABLE\_PRIVILEGES](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-table_privileges-table.md), which only lists privileges granted on the table level ([MDEV-24486](https://jira.mariadb.org/browse/MDEV-24486))

### Partitioning

- [ALTER TABLE … EXCHANGE PARTITION](https://mariadb.com/docs/server/server-usage/partitioning-tables/partitioning-overview.md#exchanging-partitions) and [ALTER TABLE … CONVERT TABLE … TO](https://mariadb.com/docs/server/server-usage/partitioning-tables/partitioning-overview.md#converting-partitions-to-from-tables) now support the `WITH VALIDATION` and `WITHOUT VALIDATION` clauses. If neither is specified, the default behavior is `WITH VALIDATION` ([MDEV-22164](https://jira.mariadb.org/browse/MDEV-22164))

### Miscellaneous Functions

- [CONV()](https://mariadb.com/docs/server/reference/sql-functions/numeric-functions/conv.md) function now supports conversion up to base 62 ([MDEV-30879](https://jira.mariadb.org/browse/MDEV-30879))
- Values generated by the Key Derivation Function [KDF](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/kdf.md) are resistant against password hashing generators, so are good for strongly hashed passwords ([MDEV-31474](https://jira.mariadb.org/browse/MDEV-31474))
- Given a time in picoseconds, the new function [FORMAT\_PICO\_TIME](https://mariadb.com/docs/server/reference/sql-functions/date-time-functions/format_pico_time.md) returns a human-readable time value and unit indicator ([MDEV-19629](https://jira.mariadb.org/browse/MDEV-19629), [MariaDB 11.0](https://mariadb.com/docs/release-notes/community-server/old-releases/11.0/what-is-mariadb-110.md))

### Date and Time

- [DATE\_FORMAT](https://mariadb.com/docs/server/reference/sql-functions/date-time-functions/date_format.md) function can now print the current time zone abbreviation and current time zone offset from UTC with `%Z` and `%z` format specifiers. ([MDEV-31684](https://jira.mariadb.org/browse/MDEV-31684), [MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md))

### Processlist

- Added a `SENT_ROWS` column to the [Information Schema PROCESSLIST](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-processlist-table.md) table, as well as extended the display size for the columns in processlist to ensure that most results will fit in display ([MDEV-3953](https://jira.mariadb.org/browse/MDEV-3953), [MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md))

### Miscellaneous

- Added support for packages ([CREATE PACKAGE](https://mariadb.com/docs/server/reference/sql-statements/data-definition/create/create-package.md)) outside of [ORACLE sql\_mode](https://mariadb.com/docs/release-notes/community-server/about/compatibility-and-differences/sql_modeoracle.md) ([MDEV-32101](https://jira.mariadb.org/browse/MDEV-32101))
- Setting a non-default [old\_mode](https://mariadb.com/docs/server/server-management/variables-and-modes/old_mode.md) value will now always issue a deprecation warning ([MDEV-31811](https://jira.mariadb.org/browse/MDEV-31811), [MariaDB 11.3](https://mariadb.com/docs/release-notes/community-server/old-releases/11.3/what-is-mariadb-113.md))
- [ALTER TABLE IMPORT](https://mariadb.com/docs/server/reference/sql-statements/data-definition/alter/alter-table.md) enhancement ([MDEV-26137](https://jira.mariadb.org/browse/MDEV-26137), [MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md))
- Temporary tables are now displayed in the [Information Schema TABLES Table](https://mariadb.com/docs/server/reference/system-tables/information-schema/information-schema-tables/information-schema-tables-table.md), [SHOW TABLES](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-tables.md) and [SHOW TABLE STATUS](https://mariadb.com/docs/server/reference/sql-statements/administrative-sql-statements/show/show-table-status.md) ([MDEV-12459](https://jira.mariadb.org/browse/MDEV-12459), [MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md))
- [Stored programs](https://mariadb.com/docs/server/server-usage/stored-routines.md): validation of stored program statements ([MDEV-5816](https://jira.mariadb.org/browse/MDEV-5816), [MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md))
- Extend [AES\_ENCRYPT()](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/aes_encrypt.md) and [AES\_DECRYPT()](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/encryption-hashing-and-compression-functions/aes_decrypt.md) to support an initialization vector and algorithm ([MDEV-9069](https://jira.mariadb.org/browse/MDEV-9069), [MariaDB 11.2](https://mariadb.com/docs/release-notes/community-server/old-releases/11.2/what-is-mariadb-112.md))
- The [transaction\_isolation](https://mariadb.com/docs/server/server-management/variables-and-modes/server-system-variables.md#transaction_isolation) option is now a system variable, and the tx\_isolation system variable is deprecated ([MDEV-21921](https://jira.mariadb.org/browse/MDEV-21921), [MariaDB 11.1](https://mariadb.com/docs/release-notes/community-server/old-releases/11.1/what-is-mariadb-111.md))
